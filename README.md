# Restaurant Management System - Frontend

React frontend with Vite and Material-UI for the restaurant management system.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create `.env` file:
   ```bash
   cp env.example .env
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

## Features

- Master Admin Dashboard
- Restaurant Management (CRUD)
- File Upload for Restaurant Logos
- Responsive Material-UI Design
- Authentication Context

## Components

- `Login` - Master admin login form
- `MasterAdminDashboard` - Main dashboard with sidebar
- `Dashboard` - Statistics and overview
- `RestaurantManagement` - Restaurant CRUD operations
